# Master Seguros 🛡️

Landing page institucional e de captação da **Master Seguros**, uma corretora de seguros premium. O site foi construído com foco em **confiança, sofisticação e experiência de aplicativo**, com efeitos dinâmicos, gradientes, tipografia refinada e identidade visual azul-marinho + dourado.

> **Slogan:** _Proteção com maestria, tranquilidade para a vida toda._

---

## ✨ Destaques

- **Design premium e responsivo** (desktop, tablet e mobile) com paleta azul-marinho profundo e dourado.
- **Carrossel** de situações de seguro e sinistro com autoplay, efeito Ken Burns, swipe, dots e barra de progresso.
- **Hero estilo app** com painel interativo, seletor rápido de coberturas e tilt 3D.
- **Menu inteligente**: dropdown de seguros no desktop e lista expandida nítida no mobile, com links para cada seguro.
- **Formulário de cadastro** para cupom de inauguração com validação completa (nome, nascimento, cidade, telefone, e-mail e endereço), máscara de telefone e estado de sucesso com cupom copiável.
- **Efeitos dinâmicos**: contadores animados, reveal on scroll, countdown de inauguração, barra de progresso de rolagem e botão flutuante de WhatsApp.
- **Acessibilidade**: suporte a navegação por teclado, `prefers-reduced-motion` e rótulos ARIA.

## 🚀 Como executar

Por ser um site estático, basta abrir o arquivo `index.html` no navegador.

Para servir localmente (recomendado, evita restrições de origem):

```bash
# Python 3
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.
